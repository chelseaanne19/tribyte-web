# Setup: from an existing GitHub repository to a working TriByte app

**You already created a GitHub repository. Keep it. Do not create another.** These instructions assume docs are provided as a ZIP and the app might not yet exist.

## Before you start

Install **Git**, **VS Code** and a current supported **Node.js LTS** version. Check [Vite's current requirements](https://vite.dev/guide/) because Node version minimums can change. Install the **Codex extension published by OpenAI** via VS Code Extensions; sign in with your ChatGPT account.

In the VS Code terminal check:

```bash
git --version
node --version
npm --version
```

## Path A — You only created an empty GitHub repository

1. From GitHub, click **Code → HTTPS** and copy the repository URL.
2. In a terminal run (replace the placeholder URL):

   ```bash
   git clone <YOUR-REPOSITORY-URL>
   cd <YOUR-REPOSITORY-FOLDER>
   ```

3. If the repo is empty (apart from `.git`), scaffold Vite **inside the current folder**:

   ```bash
   npm create vite@latest . -- --template react-ts
   ```

   The dot (`.`) means 'use this folder', not a new repository. If GitHub already created a README or `.gitignore`, Vite may warn that the directory isn't empty. **Do not select 'Remove existing files'.** You may choose to keep existing files and continue when safe; if unsure, scaffold Vite in a separate temporary folder and copy its app files into your clone without deleting `.git` or other work.
4. Choose **ESLint** if the scaffold asks for a linter.
5. **Now** extract the downloaded TriByte documentation ZIP and copy **its contents** (`README.md`, `AGENTS.md`, and `docs/`) into the repository root, replacing Vite's autogenerated README. Don't create a nested `tribyte-pocket-post-starter` directory inside your repo.
6. Then run:

   ```bash
   npm install
   npm run dev
   ```

7. Open the local URL displayed (often `http://localhost:5173/`). In a separate terminal run:

   ```bash
   npm run build
   npm run lint
   ```

8. Review `git status`, make the initial commit, and push to **your existing** GitHub repo:

   ```bash
   git add .
   git commit -m "chore: scaffold TriByte app and add product docs"
   git push -u origin HEAD
   ```

   If your repo has an initial README commit, cloning first prevents accidental divergent histories.

## Path B — You already have a local Vite/React folder

Do **not** create another Vite project. Open the existing folder in VS Code. Copy the ZIP's docs, README and AGENTS.md into its root. Confirm `package.json` exists and run `npm install`, `npm run dev`, `npm run build` and `npm run lint`.

If the local folder is **not connected** to your existing GitHub repo, follow GitHub's instructions to connect the right remote. Check `git remote -v` and `git status` first so you don't overwrite another repository. If confused, stop before force-pushing and ask for help with the terminal output.

## Your first Codex task

After setup, open `docs/codex-prompts.md` and run **Prompt 0** (inspect and explain; no edits). Then use **Prompt 1** for only the landing page. Don't ask Codex to implement the map and postcard in its first task.

## Common gotchas

- `node_modules` should be ignored by the scaffold's `.gitignore`.
- `npm run dev` keeps running; use a **second terminal** for `npm run build`.
- You don't need Supabase, Firebase, a paid map API or your own domain to begin.
- If Codex icon is missing, use VS Code Extensions to confirm Codex by OpenAI is enabled; use Command Palette or reload the VS Code window.
- Only print packaging QR codes once the public domain and `/scan` URL are stable.
